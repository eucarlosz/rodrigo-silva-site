## ✨ O que é

> *"Sua imagem comunica antes de você falar."*

Este não é um site de barbearia. É um site sobre **imagem, identidade, presença, estratégia visual e transformação**, construído em torno de um único conceito: **visagismo**.

Nada de categorias genéricas como "corte" ou "barba" — o site foi desenhado para vender percepção, não serviço.

## 📖 A história por trás do projeto

O Rodrigo é barbeiro, mas o que ele realmente vende é **transformação de percepção**. Percebendo isso, nasceu a ideia de um site que não fosse "mais um site de barbearia", mas sim uma vitrine de posicionamento — algo que comunicasse consultoria, método e autoridade em visagismo.

A primeira decisão foi de recorte: **o site falaria só sobre visagismo**. Chegamos a cogitar uma categoria "Barba" na galeria, mas descartamos — os 4 casos reais de antes/depois já eram prova social o suficiente, e menos categoria significava mais foco.

Daí vieram as camadas:

```
Posicionamento → Identidade visual → Estrutura → Prova social → Contato
```

A **estrutura** virou uma SPA leve de 3 páginas — Início, História e Eventos — navegando por hash, sem recarregar a página, sem framework, sem backend. Só HTML, CSS e JS puro, no melhor estilo "menos é mais".

Depois de pronto, o site foi publicado no **GitHub Pages**, e para dar um passo além do `.github.io`, registramos um **domínio próprio**: `rodrigosilvavisagismo.com.br`. A configuração de DNS teve seus obstáculos — uma transição que exigiu espera, um registro que ficou vazio por engano — mas terminou com sucesso: 4 registros A, um CNAME, e HTTPS ativo.

O último capítulo foi de fricção zero: todos os botões "Fale com Rodrigo" e o ícone flutuante de WhatsApp passaram a abrir a conversa com uma **mensagem automática já pronta**, encurtando a distância entre "ver o site" e "agendar um horário".

## ⚙️ Stack

```
HTML5 + CSS3 + JavaScript (vanilla)
Sem framework · Sem backend · Sem banco de dados
```

```
📁 rodrigo-silva-site
├── 📄 index.html                   → estrutura da página
├── 🎨 rodrigo-silva-estilos.css    → todo o CSS
├── ⚡ rodrigo-silva.js             → menu mobile, SPA, scroll reveal
├── 🌐 CNAME                        → domínio customizado (GitHub Pages)
└── 🖼️ assets/                      → fotos, logo, favicon
```

**JavaScript cobre:**
- 🧭 Header com blur no scroll
- 📱 Menu mobile (Esc fecha, trava scroll do body)
- 🔀 Navegação SPA (`pushState` / `hashchange` / `popstate`)
- 👁️ Scroll reveal via `IntersectionObserver`
